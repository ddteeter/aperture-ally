DESIGN NOTE {{ note }}
WHERE LIBRARY LIVES A new top-level tab, not part of Sessions. Sessions is history: what you shot. Library is the set of reusable definitions you edit between shoots. Mixing them means scrolling past 18 shoots to fix a template. They link both ways: every session row names its template, and every template shows how many shoots used it. Tab order: Shoot · Coverage · Shot list · Setup · Sessions · Library · Diagnostics. ⌘1–5 stay the same. Library takes ⌘6 and Diagnostics moves to ⌘7, since it's rarely used and is where muscle memory costs least. “Shot list” (⌘3) now edits this shoot's copy. Its header reads “from Shoe review v3” and links to the template in Library.
